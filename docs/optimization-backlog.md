- [x] **B1（✅ 轮 8）** 🔴 校验结果可见化** `[评审]` **建议最优先**
  "校验资产"失败时错误清单被吞进折叠开发者面板，用户看到"完成（无写入）"——**校验失败看起来像成功**，动摇"缺格不可导出"承诺。修：导出中心内嵌结果区（绿=就绪 / 红=缺失 clip 清单 + 跳资产库）。
- [x] **B2（✅ 轮 8）** 🟡 "生成此格"名不副实** `[评审]`
  按钮实际重生成整个资产（数十秒）而标题暗示单格。修：bridge 端点加 clip 参数（真单格）或改名"重新生成全部"+ 明示代价。
- [x] **B3（✅ 轮 8）** 🟡 "刷新本地原型对比"永远 dead** `[评审+用户]`
  `prototypes/` gitignored 且不在服务白名单，按钮只能显示"缺失"。修：server.mjs 白名单加 `/prototypes/`（本地回环暴露用户自己的图，可接受）——这是"导入自己的图后反复对比"的必要环节。
